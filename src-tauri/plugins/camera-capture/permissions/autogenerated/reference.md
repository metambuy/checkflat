## Default Permission

Allows taking a photo with the system camera app, picking an image with the system Photo Picker and resolving display names of picked files

#### This default permission set includes the following:

- `allow-capture`
- `allow-take-recovered-capture`
- `allow-pick-image`
- `allow-display-name`
