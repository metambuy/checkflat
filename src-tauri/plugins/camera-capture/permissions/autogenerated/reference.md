## Default Permission

Allows taking a photo with the system camera app

#### This default permission set includes the following:

- `allow-capture`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`camera-capture:allow-capture`

</td>
<td>

Enables the capture command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`camera-capture:deny-capture`

</td>
<td>

</td>
</tr>
