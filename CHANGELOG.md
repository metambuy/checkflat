## Sprint 4a — 2026-10-20 (photo annotation; D-027)

- Dev → Seed: "with annotations" (one ellipse + one arrow per photo, a freehand on every third) for the P30 re-measure.
- **Limits kept by the editor (PR review):** a freehand stroke ends at 2000 points and at what is left of the 6000 per photo, a photo takes no more than 50 shapes, and a muted hint says so ("Drawing limit reached — undo or delete a shape", EN/PT); before, a long scribble was refused by the core on Save with the generic validation error. - Internals: `nav.svelte.ts` back-handler stack (a modal above a screen takes Back first); `tsconfig` allows `.ts` import extensions (pure modules that import each other at runtime, as Node's test runner needs).
